# 004 — Island: Стилевое оформление часов, погоды, иконок и эффектов (Glow/Pulse)

## Контекст и цель
Данная спецификация определяет требования к дизайну и стилевому оформлению виджетов часов, погоды, наборов иконок и визуальных эффектов (свечение, подсветка, пульсация) для компонента Island в репозитории `collab-sandbox`.

---

## 1. Часы и циферблаты (Clock & Dial Styles)

Необходимо предусмотреть несколько вариантов визуального оформления с возможностью переключения через конфигурацию/настройки:

1. **Digital Modern (Цифровой стандарт):**
   - Крупный моноширинный или полужирный шрифт (e.g. Segoe UI Variable / Cascadia Code).
   - Формат 24h / 12h с регулируемым разделителем (двоеточие с опциональным миганием).
   - Минималистичный и чёткий вид для compact-режима острова.

2. **Digital Minimal (Минималистичный цифровой):**
   - Тонкое начертание (Light/UltraLight), отсутствие секунд, компактный отступ.
   - Акцент на органичную интеграцию в статус-бар без отвлечения внимания.

3. **Digital with Seconds & Milliseconds Pulse (С секундами и индикатором):**
   - Формат `HH:MM:SS` с уменьшенным кеглем для секунд или дуговым/линейным прогресс-баром текущей минуты.
   - Плавная анимация обновления секундного счётчика.

4. **Analog Minimal Dial (Минималистичный аналоговый циферблат):**
   - Векторный циферблат (SVG / WinUI Canvas) без цифр с 12 засечками.
   - Минутная и часовая стрелки с плавным ходом (`RenderTransform` / rotation).

---

## 2. Погода и виджет состояния (Weather Styles & Widget)

1. **Основные элементы:**
   - **Температура:** Чёткий вывод значения с единицей измерения (`°C` / `°F`), текстовое описание (например, "Ясно", "Пасмурно", "Снег").
   - **Иконки состояния:** Набор векторных/Fluent-иконок для базовых метеоусловий:
     - `Sun` / `Clear` (Солнечно / Ясно)
     - `Cloud` / `Overcast` (Облачно / Пасмурно)
     - `Rain` / `Drizzle` (Дождь / Ливень)
     - `Snow` / `Blizzard` (Снег / Заметь)
     - `Thunderstorm` (Гроза)
     - `Fog` / `Mist` (Туман)
   
2. **Форматы отображения (Виджеты):**
   - **Compact Badge:** Иконка + Температура (для свёрнутого острова).
   - **Expanded Widget:** Иконка + Температура + Описание + Диапазон (Min/Max) / Ощущается как (Feels like).

---

## 3. Наборы иконок статусов и уведомлений (Icon Sets)

Предусмотреть несколько стилистических сетов иконок для статусов (DND, Wi-Fi, Mute, Новые уведомления):

1. **Fluent System Icons (Default):**
   - Стандартный стиль Windows 11 / Microsoft Fluent (чистые линии, закруглённые контуры).
2. **Minimal Line Icons:**
   - Строгие контурные иконки толщиной 1.5px для минималистичных тем.
3. **Filled Active Icons:**
   - Заполненные (Solid) иконки с акцентным цветовым выделением для активных состояний (например, горит DND или есть пропущенное уведомление).

---

## 4. Эффекты свечения, подсветки и пульсации (Glow & Pulse Effects)

Для привлечения внимания и интерактивного отклика острова определены варианты визуальных эффектов:

1. **Border Glow (Свечение границы):**
   - Внешний или внутренний `DropShadow` / Neon Accent Glow вокруг границы острова.
   - Регулируемый радиус размытия (`BlurRadius`), цвет и прозрачность.

2. **Pulse Aura (Пульсация статуса):**
   - Мягкая анимация масштабирования и затухания прозрачности (Scale 1.0 -> 1.08, Opacity 1.0 -> 0.0) при получении нового уведомления или события.

3. **Subtle Background Highlight (Подсветка фона):**
   - Мягкое градиентное освещение/блик на фоне Acrylic/Mica при наведении курсора (`Hover State`).

## 5. Процесс разработки и согласования (Workflow)

В соответствии с правилами взаимодействия NB, SL и CC:

1. **Этап 1 (Подбор и описание референсов / вариантов):**
   - NB и SL подбирают варианты оформления, описывают структуру стилей/ресурсов и выкладывают предложенные варианты.
2. **Этап 2 (Утверждение у CC):**
   - Варианты и референсы передаются на утверждение CC.
3. **Этап 3 (Реализация в коде):**
   - После официального утверждения CC боты приступают к написанию и внедрению кода в папке `island/`.
