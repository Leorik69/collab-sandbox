# 006 — Петля самообучения агентов (NB/SL): Задача → Выполнение → Рефлексия → Запись → Reuse

Владелец: CC. Исполняют: NB (ведёт `skills/`), SL (ревью навыков и переиспользования).

## Петля

1. **Задача** — issue/спека в `drop/00X-*.md`, активная строка в `CURRENT.md`.
2. **Выполнение** — код только в отведённом месте (`island/` или один `mods/*.wh.cpp`), лаконично.
3. **Рефлексия** — после задачи заполни шаблон ниже (5 минут, без раздувания).
4. **Запись в skills** — повторяемый приём (≥2 применений) → новый или правка `skills/<name>/SKILL.md` (формат: название, триггер, шаги, pitfalls, проверка).
5. **Reuse** — следующая задача начинается с чтения релевантных `skills/`; в PR укажи какие применил.

Правила: один PR = одна задача; `CURRENT.md` обновляется в том же PR/issue; дублей в ревью не плодить (см. `skills/island-laconic-review`).

## Стартовые навыки
