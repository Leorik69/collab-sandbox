# 005 — Island: Пак графических ассетов (PNG/SVG) и переключатель источников иконок (FontIcon / Local Assets)

## Контекст и цель
Спецификация определяет требования к структурированию, хранению и интеграции набора локальных графических/векторных ассетов (иконки погоды и системных статусов) в проект WinUI 3 `NotifyIsland` (`island/`), а также к реализации механизма переключения источников отображения иконок в контекстном меню (ПКМ).

---

## 1. Структура графических ассетов (`island/Assets/`)

В директории `island/Assets/` необходимо организовать структуру папок для хранения графических и векторных иконок высокого качества (SVG и PNG):

```text
island/
└── Assets/
    ├── Weather/
    │   ├── sun.svg / sun.png           # Солнечно / Ясно
    │   ├── rain.svg / rain.png         # Дождь / Ливень
    │   ├── snow.svg / snow.png         # Снег / Заметь
    │   ├── storm.svg / storm.png       # Гроза
    │   └── fog.svg / fog.png           # Туман / Облачность
    └── Statuses/
        ├── dnd-active.svg / .png       # Режим "Не беспокоить" (DND)
        ├── dnd-off.svg / .png          # Стандартный режим DND
        ├── bell-unread.svg / .png      # Активные уведомления
        └── bell-none.svg / .png        # Нет новых уведомлений
```

### Требования к ресурсам:
- Все SVG и PNG должны быть оптимизированы для оверлейных панелей на темном/светлом фоне (поддержка контрастности и прозрачности).
- Ассеты погоды отражают основные метрики: солнце, дождь, снег, гроза, туман.
- Ассеты статусов отражают состояния DND и наличие/отсутствие непрочитанных уведомлений.

## 2. Подключение ассетов в WinUI 3 (`NotifyIsland.csproj`)

Для того чтобы графические ассеты из `Assets/` корректно поставлялись при сборке и были доступны приложению по URI (`ms-appx:///Assets/...`), в `NotifyIsland.csproj` добавляется конфигурация `Content`:

```xml
<ItemGroup>
  <Content Include="Assets\**\*">
    <CopyToOutputDirectory>PreserveNewest</CopyToOutputDirectory>
  </Content>
</ItemGroup>
```

## 3. Расширение настроек и переключатель в ПКМ

1. **Модель настроек (`IslandSettings.cs`):**
   - Добавить/расширить перечисление `IconSourceMode` (или обновить `IconSet` / добавить новый переключатель `IconSource`):
     - `FontIcon` (Системные шрифтовые иконки Segoe Fluent Icons / Segoe MDL2)
     - `LocalAsset` (Локальные графические PNG/SVG ассеты из `Assets/`)

2. **Контекстное меню ПКМ (`MainWindow.xaml.cs`):**
   - В меню ПКМ добавить пункт управления источником иконок:
     - `Icon Source -> FontIcon (System) / Local Assets (PNG/SVG)`
   - Изменение выбора немедленно переключает отображение иконок погоды и статусов без перезапуска приложения и сохраняет настройку в `LocalSettings`.

3. **Код отображения (`MainWindow.xaml.cs` и `MainWindow.xaml`):**
   - В UI разметке и коде предусмотреть контейнеры для отображения как `FontIcon`, так и `Image` / `SvgImageSource` (или динамическую подмену элементов/источников).
   - В методах `ApplyWeather()` и `ApplySettings()` реализовать логику выбора ресурса:
     - При режиме `FontIcon` устанавливается значение `Glyph`.
     - При режиме `LocalAsset` устанавливается `Source = new SvgImageSource(new Uri("ms-appx:///Assets/Weather/sun.svg"))` или соответствующий PNG ресурс.
