# 008 — Ideal notification UX (PLAN ONLY)

Do not implement this in code. Implementation **waits on UX research** (CC screens / refs). This file is a short plan, not a build spec.

## States

- **idle** — small pill, clock only.
- **notification** — expands (morph): app icon + counter.
- **several apps** — row of icons in the pill.
- **click icon** → that app’s notifications.

Ideal UX code is pending UX research. Bugs a–d (chrome, morph, hover, RMB) are separate and are not this UX.
