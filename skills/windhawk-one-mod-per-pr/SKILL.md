# windhawk-one-mod-per-pr

Триггер: новый Windhawk-мод, сплит большого PR, или ревью PR с несколькими `.wh.cpp`.

Шаги:
1. Один PR = один мод = один файл `mods/<name>.wh.cpp` (или согласованный путь в спеке).
2. В теле PR: краткое описание + блок `## Mod authorship` (кто писал / кто ревьюил).
3. Не смешивай несвязанные моды, рефактор чужих модов или правки вне этого файла в тот же PR.
4. Если исходник большой — сплить заранее на N PR по одному `.wh.cpp`, не «потом».

Pitfalls:
- Не пихай несколько модов «чтобы быстрее смержить».
- Не трогай чужие репозитории / чужие PR вне явного scope.
- Draft/старый большой PR не расширяй новыми модами — сплит.

Проверка: diff PR содержит ровно один новый/изменённый мод-файл; описание и authorship на месте.
